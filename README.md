# LAN-Design
# he floor plans show the designated locations of computers, network devices, and cable pathways to ensure proper connectivity between the different rooms and workstations. The ceiling cabling layout also presents the planned routes for organizing and distributing network cables across the designated areas. This design aims to provide an organized, efficient, and reliable Local Area Network (LAN) infrastructure. Proper cable placement and routing help minimize cable clutter, simplify maintenance and troubleshooting, and support stable network communication throughout the building.
